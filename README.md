# 🏦 Full Banking System

A complete banking system written in C with ncurses GUI.

## ✨ Features

- ✅ User registration and login
- ✅ Multiple account types (savings, checking)
- ✅ Deposit and withdraw money
- ✅ Transfer between users
- ✅ Transaction history
- ✅ Interest calculation
- ✅ Loans
- ✅ Admin panel
- ✅ Save/Load data
- ✅ ncurses GUI

## 🚀 How to Compile

```bash
gcc -Wall -Wextra -o banking main.c -lncurses
```
## 🏃 How to Run
```bash
./banking
```
